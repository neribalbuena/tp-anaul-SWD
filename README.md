# QuickShop 🛒

QuickShop es un proyecto de desarrollo web que consiste en un catálogo digital para un supermercado, acompañado de un panel de administración que permite gestionar los productos de manera sencilla y organizada.

## Funcionalidades

- Visualización del catálogo de productos.
- Consulta de precios, categorías y stock disponible.
- Incorporación de nuevos productos.
- Modificación de productos existentes.
- Eliminación de productos.
- Almacenamiento de información mediante SQLite.

## Tecnologías utilizadas

- HTML: estructura de las páginas.
- CSS: diseño y presentación visual.
- JavaScript: interacciones y lógica del cliente.
- Node.js: entorno de ejecución del servidor.
- Express: gestión de rutas y solicitudes.
- EJS: generación de páginas dinámicas.
- SQLite: almacenamiento de los productos.

## Instalación y ejecución

Para ejecutar el proyecto, es necesario tener instalado [Node.js](https://nodejs.org/).

1. Clonar el repositorio

```bash
git clone https://github.com/neribalbuena/tp-anaul-SWD.git
```

2. Ingresar a la carpeta del proyecto
   
```bash
cd tp-anaul-SWD
```

3. Instalar las dependencias
   
```bash
npm install
```

4. Iniciar el servidor

```bash
node server.js
```

5. Acceder desde el navegador

Abrir la siguiente dirección:

```text
http://localhost:3000
```
